Lab Test Demand Count CLI

A Python-based Command Line Interface (CLI) project for analyzing laboratory test demand using data stored in JSON format.

Project Overview

This project processes laboratory test request data from a JSON file and provides useful demand-related information through a command-line interface.

Features

Read laboratory test request data from a JSON file
Analyze lab test demand
Display results through a command-line interface
Perform data-based counting and analysis
Technologies Used
Python
JSON
Command Line Interface (CLI)

Project Structure


Lab-Test-Demand-Count-CLI/

│

├── Lab_Test_Demand_Count.py

├── main.py

How to Run

Clone or download the repository.
Open the project folder.
Make sure Python is installed.
Run the Python program from the terminal.
python Lab_Test_Demand_Count.py

Data Source

The project uses test_requests.json as the input data source.

Purpose

The main purpose of this project is to demonstrate Python programming, JSON data handling, and command-line based data analysis.
